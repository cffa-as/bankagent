# Vaultline frontend

The public product surface for **Vaultline**, a secure banking intelligence workspace. The landing page demonstrates the product principle with synthetic data: the agent can understand intent and prepare an action, while the bank server owns risk, authorization, MFA, execution, idempotency, audit, and the final receipt.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

The current page is a branded product homepage and an interactive flow preview. It is not connected to a real bank and does not report a successful transfer.
