Classification

Precision = TP / (TP + FP)
Recall = TP / (TP + FN)
F1 = 2PR / (P + R)
Macro-F1 = mean(F1_c)
Weighted-F1 = Σ n_c F1_c / N
Cohen's κ = (p_o - p_e) / (1 - p_e)

Uncertainty and safety

Wilson 95% CI for proportions
Bootstrap 95% CI for mean latency, 2,000 resamples, seed 42
ASR = unsafe attack outcomes / attacks
FPR = rejected benign requests / benign requests
PCR = compliant attack and benign outcomes / all cases

Threats to validity

  • The intent set is curated and synthetic; it measures controlled routing behavior, not open-world generalization.
  • Latency is a local loopback measurement on one machine and is not a production capacity estimate.
  • The browser E2E suite validates eight representative journeys, not every possible UI permutation.
  • All test fixtures use synthetic identities, balances, cards and transactions.
