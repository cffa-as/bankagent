# Vaultline 演示视频 v0 重制提示词

> 用途：复制给 v0，生成 16:9、4:30–4:50 的完整产品演示分镜与可运行视频工程。

```text
你是一名银行产品设计总监、动效导演和 Remotion 工程师。请基于 GitHub 仓库 cffa-as/bankagent 制作一套约 4 分 40 秒的 Vaultline 产品演示视频工程。

目标：
生成 1920×1080、30fps、16:9 的完整产品演示，用于金融科技比赛答辩。它不是宣传片合集，也不是功能清单，而是一条连续的产品叙事，必须展示真实前端交互、复杂业务操作、服务端权限边界和最终业务回执。

视觉方向：
- 70% 以上画面使用浅色、专业的银行工作台界面，不要整段黑底。
- 品牌色：深海军蓝 #0B1423、铂金灰 #F7F9FC、钴蓝 #315BFF；黄色只表示需要确认，红色只表示 MFA 或高风险。
- 字体：中文 Noto Sans SC/PingFang SC，英文标题 Space Grotesk，金额与 ID 使用 JetBrains Mono。
- 不使用紫蓝 AI 渐变、玻璃拟态、霓虹、机器人插画、夸张 3D 卡片或无意义粒子。
- 动效只响应真实用户动作和状态变化，不使用假进度条、假思考动画或伪造成功状态。

叙事与镜头：
1. 0:00–0:12 品牌开场
   小尺寸 Vaultline Reserve 标识居中，深海军蓝文字出现在浅色背景上；一句话“银行业务，一句话开始”。

2. 0:12–0:30 问题与产品定位
   展示传统菜单路径与长表单的快速蒙太奇，随后切到 Vaultline 工作台首屏。强调“模型提议，银行服务端裁决”。

3. 0:30–1:00 简单转账与业务回执
   在真实工作台输入“给张三转 300 元，备注项目款”。
   展示 Agent 流式步骤、不可修改的动作快照、黄色确认、服务端回执和 Trace ID。
   成功只能出现在银行返回回执之后。

4. 1:00–1:30 复杂转账：预约与 AA
   展示“这周五给张三转 500 元交房租”的预约转账确认状态。
   展示“1200 元四人 AA，由我收款”的拆分收款动作，明确每人应付金额和付款人。
   不要伪造扣款结果；只展示服务端创建的动作或收款请求回执。

5. 1:30–2:00 账单分析与异常解释
   在真实工作台查询交易记录和本月消费。
   展示分类占比、异常交易、规则依据和 Trace。

6. 2:00–2:35 理财申购与赎回
   展示产品比较、风险等级、起购金额和期限。
   输入“申购稳健理财 100 元”，展示风险确认、Action 绑定 MFA、执行和持仓回执。
   再展示赎回动作进入红色 MFA，最终显示本金与收益回执。

7. 2:35–3:05 卡片与订阅
   展示卡片状态查询、冻结确认和高风险挂失/解挂 MFA 状态。
   展示订阅续费提醒、取消前快照、黄色确认和取消回执。
   不展示真实卡号，只显示脱敏尾号。

8. 3:05–3:30 流动性预检
   提问“预留 2000 元会影响未来 30 天的必要支出吗？”
   展示四种现金流情景、逐日曲线、最低余额、最大安全预算和替代方案。

9. 3:30–4:05 跨场景 DAG
   输入“爱人生日预算 1000 元，日期 2026-11-08”。
   展示提醒、预算锁定、鲜花和蛋糕节点的依赖关系。
   展示预算锁 MFA、提醒完成、订单确认、业务回执和部分完成状态。
   强调每一步独立授权，Agent 不得一次性越过确认。

10. 4:05–4:25 运行控制
   展示 Agent 执行轨迹、停止运行、转人工接管，以及撤销待执行动作。
   已执行动作必须显示“进入人工复核”，不能表现为静默冲正。

11. 4:25–4:40 安全边界
   连续展示提示注入、金额篡改、重复确认和 MFA 失败。
   每次拒绝都指向稳定的错误说明和审计记录，账户不发生变化。

12. 4:40–4:50 结束
   回到浅色品牌画面：“模型提议 · 服务端裁决 · 回执证明结果”。
   显示“合成演示数据”声明。

实现要求：
- 优先复用真实产品截图、工作台 DOM 和现有视觉组件，不要重新发明一套银行界面。
- 如果 v0 当前环境不能连接 Go API，请把真实截图作为主画面，用清晰的局部高亮、放大、遮挡和字幕完成镜头；不要伪造无法验证的成功结果。
- 输出 Remotion 或等价可运行视频工程，包含场景配置、字幕、时间轴、品牌组件和镜头参数。
- 视频必须可在后续替换真实录屏片段，不要把字幕、界面和业务状态焊死在图片里。
- 结尾提供一份 scene coverage 清单，逐项映射到智能转账、账单分析、理财、卡片、订阅、跨场景联动和运行控制。
- 所有账户、金额、动作、验证码和回执均为合成数据。
```

## 验收清单

- 视频长度不超过 5 分钟。
- 至少完整展示 3 个业务场景，目标覆盖全部 6 个场景。
- 每个复杂动作都有动作快照、授权方式和服务端结果。
- 预约转账、AA 拆分、理财申购/赎回、卡片高风险操作、订阅取消和跨场景 DAG 不得只停留在查询层。
- 运行控制和异常安全场景至少有各一个完整镜头。
- README 只链接新版完整演示，不再保留 30 秒品牌片。
