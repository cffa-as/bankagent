# Vaultline 作品简介

> 报名系统提交版，含标点共 199 个字符，满足“200 字以内”要求。

Vaultline 是面向手机银行的自然语言 AI 智能体。用户描述需求后，可理解模糊和省略表达，并通过受控工具办理转账、账单、理财、卡片、订阅和跨场景任务。模型仅生成候选计划；风险分级、动作快照、确认、Action 绑定 MFA、幂等执行、审计和最终回执由 Go 服务端裁决。支持流式执行轨迹、中断、人工接管和安全撤销，以可验证边界抑制幻觉与提示注入，让“说话就能办业务”既流畅又可审计、可控制。

## 一句话介绍

Vaultline 让用户用一句话办理银行业务，同时由服务端掌控风险、授权、执行与回执。
