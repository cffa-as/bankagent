## 文档原则

- 外部文档描述产品行为、公开契约和可验证证据。
- 不公开内部项目名、个人路径、API Key、TTS 配置或本机工具链细节。
- 成功状态必须对应真实服务端回执，不使用演示文案替代业务结果。
- 涉及权限、MFA、幂等、审计或执行边界的修改，必须同步更新技术文档、OpenAPI 和测试。
