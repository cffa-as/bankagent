# Vaultline 产品演示视频方案

> 状态：已完成。当前包含 30 秒品牌片和 3:46 完整业务演示。

## 目标

演示视频需要同时完成三件事：

1. 让评委快速理解 Vaultline 的产品价值。
2. 展示六个核心业务场景和真实服务端交互。
3. 证明风险分级、确认、MFA、审计和最终回执均由银行服务端控制。

视频只使用合成账户、合成交易和本地演示账本，不出现真实个人信息、完整账户号、Token、密码或真实验证码。

## 当前成片

### 30 秒品牌片

- 用途：首页、README 和项目路演开场。
- 内容：自然语言输入、动作快照、风险判定、MFA、业务回执和审计追踪。
- 风格：深墨蓝、铂金灰和克制钴蓝，强调银行控制面而不是通用聊天产品。

### 3:46 完整业务演示

- 用途：技术评审和答辩。
- 覆盖：智能转账、交易与账单分析、实时 Agent 轨迹、理财产品、卡片、订阅、流动性预检、跨场景计划、确认、MFA、提示注入拒绝和审计记录。
- 原则：成功画面必须对应真实服务端回执，不使用虚构余额、进度或交易结果。

## 制作流程

1. 启动生产构建的 Next.js 前端和 Go API。
2. 使用全新本地账本，按场景创建独立合成会话。
3. 自动驱动真实页面完成业务操作，并录制浏览器画面。
4. 生成中文旁白、章节标题和字幕。
5. 使用代码化动效统一品牌片头、镜头运动、证据标签和转场。
6. 导出 16:9、H.264/AAC 的 MP4，并生成 README 封面和播放海报。
7. 检查字幕、敏感信息、服务端状态和最终文件尺寸。

详细工程说明见 [视频工程](../video/README.md)。

## 内容结构

| 章节 | 核心信息 |
| --- | --- |
| 品牌开场 | 面向个人客户的多渠道 AI 银行智能体 |
| 一句话开始 | 自然语言替代深层菜单和长表单 |
| 消费洞察 | 交易、账单、分类与异常分析来自服务端事实 |
| 实时执行轨迹 | 用户能看见 Agent 的计划、工具和状态推进 |
| 理财、卡片、订阅 | 不同风险动作进入统一授权状态机 |
| 流动性预检 | 用确定性现金流模型判断未来资金影响 |
| 跨场景计划 | 复杂需求拆解为有限 DAG 和逐项授权 |
| 执行与回执 | 确认或 MFA 通过后，成功只认业务回执 |
| 安全边界 | 提示注入、篡改和越权无法改变服务端策略 |
| 审计与收束 | 每个动作都有可追溯的记录和最终状态 |

## 视觉规则

- 比例：1920×1080、30fps。
- 色板：深墨蓝、铂金灰、克制钴蓝；黄色和红色仅用于表达授权风险。
- 字体：中文 Noto Sans SC / 苹方，英文和标题 Space Grotesk，编号使用 JetBrains Mono。
- 动效：只响应用户动作和真实状态变化，不使用假进度。
- 字幕：每屏最多两行，先讲用户动作，再讲服务端判断。

## 质量检查

- 视频时长、分辨率、编码和音轨正确。
- 所有成功状态均来自真实 API 回执。
- 画面不包含真实个人信息、凭据或完整账户号。
- 字幕与旁白一致，关键按钮、风险和回执可读。
- 首页、README、README.en 的视频链接有效。
