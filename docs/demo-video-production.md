# Vaultline 产品演示视频制作方案

> 状态：暂缓，不属于当前代码仓库评审范围。

## 目标

制作一条 3–5 分钟的 Vaultline 产品介绍视频。首页 GIF 只承担“看一眼就理解品牌和安全边界”的任务；长视频负责讲清完整产品价值、真实业务操作和安全控制链路。

视频使用合成账户和本地账本。所有资金结果、交易回执和 MFA 画面都必须明确标注为演示数据。

## 推荐制作路线

### A. 产品主片：Remotion + 真实前端录屏

Remotion 负责品牌片头、章节标题、状态卡片、Action ID、Trace ID、风险颜色、镜头转场和字幕。它用 React 组件生成视频，可以在浏览器预览后直接渲染 MP4，也可以导出 GIF。这样品牌视觉可以和 Vaultline 首页保持一致，后续修改页面文案或颜色时也能复用组件。

真实前端操作使用 Chrome 或 Screen Studio 录制，再把录屏作为 Remotion 的视频素材嵌入章节。这样既有真实 API 交互，也有可控的产品级镜头。

### B. 真实操作短片：Screen Studio 或 Tella

用于录制“用户真的如何使用工作台”。录屏时只保留一个浏览器窗口，使用合成账户，隐藏 token、验证码和本地调试日志。每个镜头只讲一个任务，通过自动缩放、光标高亮和字幕把注意力放到输入框、动作快照、确认按钮和服务端回执上。

### C. 交互式文档：Supademo

如果需要放到 README、答辩材料或项目官网中，可以把同一条真实录屏拆成可点击步骤。它适合产品导览和文档，不作为答辩主视频的唯一交付物，因为评委需要看到连续的叙事和完整的安全链路。

## 4 分钟成片脚本

| 时间 | 章节 | 画面 | 观众要记住的点 |
| --- | --- | --- | --- |
| 0:00–0:15 | 品牌开场 | Vaultline 六边形标识、深色网格、自然语言输入出现 | 这是面向银行业务的 AI 工作台 |
| 0:15–0:40 | 产品问题 | 传统菜单路径快速闪过，切入一句话请求 | 用户表达需求，不需要记住功能入口 |
| 0:40–1:15 | 智能转账 | 输入“转 500 元给王明”，展示 Action 快照、黄色确认、服务端回执 | 模型准备动作，服务端决定是否执行 |
| 1:15–1:40 | 账单分析 | 展示消费分类、月度账单、异常交易解释和 Trace ID | 查询类业务可以直接返回事实，不产生执行权限 |
| 1:40–2:10 | 理财操作 | 查看产品、风险评估、赎回动作进入红色 MFA 门 | 高风险操作必须经过 Action 绑定的 MFA |
| 2:10–2:35 | 卡片管理 | 冻结卡片、额度调整、解冻请求展示不同状态 | 卡片动作也遵循同一套授权状态机 |
| 2:35–2:55 | 订阅管理 | 识别周期扣费、展示取消前快照、等待服务端结果 | 取消订阅是可审计的业务动作 |
| 2:55–3:25 | 跨场景联动 | “爱人生日”拆成预算锁定、鲜花、蛋糕等子任务 | 复杂需求拆成可审核工作流，不能一次性越权执行 |
| 3:25–3:45 | 安全边界 | 提示注入、篡改金额、重复确认被拒绝并记录 Trace | 模型不能改写银行控制面 |
| 3:45–4:00 | 收束 | 回到品牌标识，出现“MODEL PROPOSES / BANK SERVER DECIDES” | 结果只来自服务端业务回执 |

## 录制顺序

1. 启动本地后端和前端，确认 OpenAPI 与页面状态一致。
2. 为每个场景准备单独的合成会话，避免前一个动作影响下一个场景。
3. 先录无旁白的干净操作素材，再统一写旁白和字幕。
4. 每个场景保留三秒空镜，方便 Remotion 做转场和节奏调整。
5. 录制成功、拒绝、MFA 失败、过期和重复确认等状态时，画面必须以服务端响应为准。
6. 导出 16:9 主片、60–90 秒答辩版和 6–10 秒首页 GIF；三种素材共享同一套色板、字体、文案和品牌标识。

## 视觉规则

- 画面比例：主片 1920×1080，答辩版同样使用 16:9。
- 色彩：深墨蓝、铂金灰、克制钴蓝；黄色和红色只表示授权风险，不作为装饰霓虹。
- 字体：中文使用 Noto Sans SC / 苹方，英文和标题使用 Space Grotesk，ID 使用 JetBrains Mono。
- 动效：输入、聚焦、确认、MFA 和回执采用 150–220ms 的轻动效；章节切换使用 350–500ms 的镜头过渡。
- 字幕：每屏最多两行；先讲用户动作，再显示服务端判断。
- 画面中不要出现真实姓名、完整账号、真实验证码、Token 或未由服务端返回的成功信息。

## 工具选择

| 目标 | 工具 | 适合 Vaultline 的原因 |
| --- | --- | --- |
| 品牌化主片 | Remotion | 视觉可代码化、可复用首页组件、可渲染 MP4 / GIF |
| 真实操作录制 | Screen Studio | 自动缩放、光标和点击动画适合展示工作台操作 |
| 快速剪辑 | Tella | 支持多段录制、自动缩放、字幕和 4K 导出 |
| 可点击文档 | Supademo | 可把截图或录屏拆成带步骤的交互式导览 |
| 免费多窗口录制 | OBS | 适合同时录制浏览器、终端和旁白，成本最低 |
