# bankagent 安全自评报告

> 版本：v0.2 · 适用范围：比赛演示版 · 数据范围：本地演示账本

## 1. 结论

当前实现可以在本地演示环境完成“自然语言请求 → 服务端动作 → 黄色确认或红色 MFA → 业务回执”的安全链路。生产级外部接入不在当前范围。

## 2. 控制项自评

| 控制项 | 当前实现 | 证据/限制 |
| --- | --- | --- |
| 权限分级 | 已实现 | 绿色查询自动执行；黄色动作确认；红色动作绑定 MFA。规则在 Go 服务端。 |
| 动作快照 | 已实现 | 金额、收款人、产品和有效期随 Action 保存；关键字段变化需重新创建动作。 |
| 幂等 | 已实现 | 副作用请求要求 `Idempotency-Key`；相同键复用结果，指纹变化拒绝。 |
| 一次性执行门 | 已实现 | 动作状态和 SQLite 条件更新共同控制确认/MFA 与执行竞争。 |
| MFA | 演示实现 | 固定演示验证器，错误 3 次锁定 Action。 |
| 审计 | 已实现 | Trace、动作、授权和工具回执进入追加式审计索引；敏感字段不写入日志。 |
| 提示注入防御 | 已实现基础控制 | 模型只输出候选计划；工具白名单、Schema、风险和授权不受用户 Prompt 改写。 |
| 结果防幻觉 | 已实现 | 成功状态来自业务工具回执；前端不乐观宣称成功。 |
| 对话上下文 | 演示实现 | 保存最近用户消息，仅 30 分钟内最近 6 条用于追问补全；读取按会话和用户隔离，尚未实现生产级留存/删除策略。 |
| 日累计复核 | 已实现 | 黄色转账在确认/触发时再次读取当日流水，超过 1000 元会失败并要求重新发起。 |
| 预约动作 | 演示实现 | 授权后进入 `scheduled`，到点需显式 trigger；仍经过动作状态、幂等和日累计复核。 |
| 预算锁定 | 已实现 | `reserved_minor` 占用可用余额，订单只能消费已锁定额度，取消/完成时释放。 |
| 流动性预检 | 已实现 | Go 按事件流计算三种情景；返回逐日曲线、最低余额、风险原因和假设，模型不能改写计算结果。 |
| 异常熔断 | 部分实现 | MFA 错误锁定和失败状态已覆盖；远程工具熔断、限流和告警尚未接入。 |
| 代码执行隔离 | 未启用 | 系统不允许模型生成或执行任意代码，因此没有脚本执行入口。 |
| 数据隔离 | 演示级 | 服务端校验 Demo 用户和资源归属；仅使用本地合成数据。 |

## 3. 已知风险

1. Demo Token 是固定演示身份，不能用于生产认证。
2. SQLite 适合单机/单实例演示；没有多实例高可用、密钥托管和灾备能力。
3. 独立 MCP Server 当前未启动；进程内 Tool Registry 是边界原型，尚未接管全部领域副作用。跨进程部署时必须补服务间认证、超时、对账和监控。
4. 跨场景 Workflow 使用显式 `advance`/`virtual_now` 推进，没有常驻后台调度器；进程退出期间不会自动执行预约任务。
5. AA 拆分只登记收款请求，不向其他参与人扣款；鲜花/蛋糕订单不连接外部商户。
6. 理财收益按固定产品规则计算，不构成收益承诺。
7. 汇率、真实风控评分、真实适当性评估和交易对账尚未接入。
8. 审计事件当前在业务事务提交后追加，不是同一事务或 outbox；极端数据库故障下可能出现业务已提交但审计不完整，请求会返回错误而不是伪报成功。
9. 当前副作用在本地 SQLite 中同步完成，`reconciliation_required` 尚未接入远程工具超时/未知回执链路。
10. 流动性预检是基于预置现金流和历史消费的 what-if 结果，不构成未来余额保证或投资建议。

## 4. 发布前必须补充

- 接入真实身份、设备绑定、MFA 和密钥托管方案。
- 为远程工具补 mTLS/Bearer Token、限流、超时、对账和告警。
- 做并发、故障注入、依赖升级和第三方安全测试。
- 对所有敏感字段执行脱敏、加密、留存和删除策略评审。
